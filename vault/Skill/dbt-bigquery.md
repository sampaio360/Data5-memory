# 📊 dbt-bigquery

**Tipo:** Engenharia de Dados (Prioridade 1 - Ativa)  
**Conexões:** Acionada sob demanda de modelagem SQL. Integra-se com `[[developing-with-bigquery]]`.

---

## 📌 Descrição
Habilidade especializada na modelagem, testes e documentação de dados utilizando o **dbt (data build tool)** voltado para o BigQuery. Focada em SQL modular, macros Jinja, testes de unicidade/nulos e versionamento de modelos.

---

## 🎯 Gatilhos de Ativação
* Presença do arquivo `dbt_project.yml` no workspace.
* Criação de arquivos `.sql` dentro de diretórios `models/`.
* Comando CLI `dbt run` ou `dbt test`.
