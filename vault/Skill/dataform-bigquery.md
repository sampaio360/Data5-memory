# 🎛️ dataform-bigquery

**Tipo:** Engenharia de Dados (Prioridade 1 - Ativa)  
**Conexões:** Acionada sob demanda de modelagem SQLX. Alternativa ao `[[dbt-bigquery]]`.

---

## 📌 Descrição
Manual avançado para criação e execução de pipelines usando o **Dataform** no BigQuery. Ensina a construir tabelas, views, declarações de fontes e testes de qualidade de dados usando arquivos `.sqlx` (SQLX).

---

## 🎯 Gatilhos de Ativação
* Presença do arquivo `workflow_settings.yaml` ou `dataform.json` no workspace.
* Edição de arquivos com extensão `.sqlx`.
