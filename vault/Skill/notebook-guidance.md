# 📓 notebook-guidance

**Tipo:** Utilidades (Prioridade 1 - Ativa)  
**Conexões:** Conectada a `[[managing-python-dependencies]]` e `[[developing-with-bigquery]]`.

---

## 📌 Descrição
Guia sobre o uso de Notebooks Jupyter para análise exploratória de dados. Instrui o agente a preferir a integração da extensão `%%bqsql` (magics de BigQuery) em vez de instanciar clientes tradicionais do BigQuery em Python dentro de células de notebook.

---

## 🎯 Gatilhos de Ativação
* Criação ou edição de arquivos de formato Notebook Jupyter (`.ipynb`).
* Análises exploratórias de dados do BigQuery feitas de forma interativa.
