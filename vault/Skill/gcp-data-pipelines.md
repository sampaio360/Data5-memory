# 🗂️ gcp-data-pipelines

**Tipo:** Engenharia de Dados (Prioridade 1 - Ativa)  
**Conexões:** Ponto de entrada do GCP. Roteia para `[[dbt-bigquery]]`, `[[dataform-bigquery]]` e `[[gcp-pipeline-orchestration]]`.

---

## 📌 Descrição
Manual e catálogo de boas práticas para a criação e orquestração de pipelines de dados no Google Cloud Platform. Ajuda a definir qual a melhor stack tecnológica para resolver problemas de ETL (Batch ou Stream).

---

## 🎯 Gatilhos de Ativação
* Construção de novos fluxos de carregamento de dados.
* Solicitações sobre arquitetura de dados no GCP (Composer, Dataflow, Dataproc, DTS, BigQuery).
