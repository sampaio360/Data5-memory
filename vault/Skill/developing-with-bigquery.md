# ⚡ developing-with-bigquery

**Tipo:** Engenharia de Dados (Prioridade 1 - Ativa)  
**Conexões:** Conectada a `[[dbt-bigquery]]`, `[[dataform-bigquery]]` e `[[discovering-gcp-data-assets]]`.

## 📌 Descrição
Repositório de boas práticas específicas do motor do BigQuery. Abrange otimização de custo de query (particionamento, clusterização), uso de funções analíticas, modelagem em estrela e consultas BigQuery ML / BigFrames em Python.

---

## 🎯 Gatilhos de Ativação
* Queries SQL complexas direcionadas ao BigQuery.
* Script Python usando as bibliotecas `google.cloud.bigquery` ou `bigframes`.
